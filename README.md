# Swole Clicker
A free single-file HTML5 idle/clicker game. Do reps, buy gym gear, steroids & supplements,
and grow a procedurally-drawn stick-figure lifter from noodle arms to absolute unit.

**Play:** https://calamborn-maker.github.io/swole-clicker/

Single self-contained `index.html` — vanilla JS, no build step. Saves locally (localStorage).
